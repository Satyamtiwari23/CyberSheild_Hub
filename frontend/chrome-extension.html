📥 Installation Instructions

  1. Download the extension package when available.
  2. Open chrome://extensions in Chrome.
  3. Enable Developer mode.
  4. Select Load unpacked.
  5. Choose the CyberShield extension folder.

🛡️ About Browser Guard

CyberShield Browser Guard is intended as an additional security layer. Always verify suspicious websites, messages, and requests independently before entering passwords, payment information, or other sensitive data.
